# 至尊牛牛 — 游戏规则说明书

> 面向产品/运营/玩家说明；数值以游戏内及后台实时配置为准。  
> 对应 PRD：`01-产品需求文档-PRD.md` 第 5 章。
> 玩家端规则说明、数值摘要、奖励与排行榜均按当前游戏的 `gameCode` 读取；本文件是至尊牛牛的只读基线与接口加载失败兜底。

---

## 1. 游戏简介

至尊牛牛是基于 Touch n Go eWallet 红包链接的多人对战玩法。

每局由一位玩家通过竞标庄钱做「庄家」，闲家自由下注；系统统一发出 TNG 红包链接；按抢到的金额识别「点数/牌型」并比对庄闲大小；胜者按倍数赢取庄家筹码；平台抽取小额抽水。

---

## 2. 在哪里玩

本游戏只有一个入口「至尊牛牛」，对局在 Mini App 的 **「至尊牛牛互动群」**（网页群聊）内进行。请先通过 Telegram Bot「进入游戏厅」，再从大厅或消息页进入互动群。

竞标庄钱、下注、撤回、群聊天、抢包与成绩单都在该互动群内完成。Telegram Bot 只负责打开游戏厅与发送私聊通知，不是 Telegram 真群对局。

**产品关系固定为「一款游戏 = 一个互动群」**。当前只上线「至尊牛牛」，所以系统中只能出现至尊牛牛及其唯一互动群，不存在“至尊牛牛 1 号桌 / 2 号桌”或任意新建群。未来新增互动群时，必须同时新增一款具有独立规则、配置与结算引擎的新游戏。

## 3. 角色说明

### 庄家

- 通过竞标庄钱上庄获得。
- 承担本局所有已下注闲家的输赢。
- 赔付上限为庄池金额，不会超过庄池亏损。
- 庄家盈利时，平台从盈利中抽取庄家抽水（默认 5%）。
- 通过公开竞标取得庄位后，本局结束可选择「续庄」，沿用相同庄钱再坐一局；连续坐庄最多两局。

### 闲家

- 未做庄的其他玩家，可在下注阶段与庄家对赌。
- 不下注即视为本局弃权。
- 赢家：按牌型倍数 × 下注获得收益（扣除闲赢抽水，默认 5%）。
- 输家：下注全数归庄家。
- 未下注/弃权：本局不结算，余额不变。

## 4. 游戏流程

### 4.1 大厅阶段

玩家进入对应群组房间等待开局；系统在凑够最低人数后自动开启下一局。

### 4.2 上庄 · 竞标庄钱

1. **全体玩家**可在竞标窗口（默认 **30 秒**，后台可配）内发送金额参与竞标；再次发送金额视为修改最终报价。  
2. 每次出价后，小助手会 **@ 该玩家** 播报出价金额、当前最高价，并询问「还有没有更高的」。  
3. 出价窗口结束后，小助手先播报本局全部出价名单，再依次各发一条 **3**、**2**、**1**，然后锁定最高有效出价者为庄家，金额冻结为「庄池」。  
4. **续庄**：公开竞标中标局结算后，小助手会询问本局庄家是否继续做庄；只有紧邻上一局的庄家可在倒计时内确认。确认后沿用上一局庄钱、跳过竞标直接开注。每次竞标中标后最多续一次，因此连续坐庄最多两局；第三局必须恢复公开竞标。上一任庄家仍可正常参与，若再次以最高有效价中标，会开启新一轮的一次续庄资格。  
5. **无人竞标庄钱**：本局取消，不进入下注阶段。  
6. **余额不足**：系统拒绝竞标并提示（出价需能覆盖庄钱 + 上庄费 + 服务费）。

### 4.3 下注阶段

1. 除庄家外的玩家可在「下注范围」内下注，倒计时（示例 50 秒）结束即停止；聊天内倒计时与顶栏共用截止时间，每秒同步刷新。  
2. **下注范围动态调整**：下注上限约为庄钱的 0.5%、梭哈上限约为庄钱的 5%（人数少时适当上调），以开注播报为准。示例：庄钱 5000 → 下注 2~25 / 梭哈 20~250；庄钱 10000 → 下注 2~50 / 梭哈 20~500。  
3. **下注方式**：在游戏房操作区输入金额下注；或选择梭哈。封盘前可撤回。  
4. **未下注**：视为弃权，不参与结算（不赢不输）；**未下注也无法抢红包**。  
5. **下注成功**：金额从余额中冻结，等待结算。  
6. **撤回下注**：封盘前发送 `0` 可撤回本局下注，冻结金额即时退回。

### 4.4 系统发包

下注阶段结束后，由**系统后台红包脚本**统一发出 TNG 红包链接到游戏群。

- **抢包资格：仅限本局参与者（庄家 + 已下注的闲家）**；未下注无法抢包。  
- 红包发出后游戏房内 **30 秒倒计时**，倒计时结束红包过期，未抢部分不再可领。  
- 抢到金额即为本人本局的「红包金额」。  
- 用户点击链接跳转至 TNG eWallet 领取。  
- 禁止玩家私下分享或冒充系统链接。

### 4.5 抢额识别

系统根据发包账号的领取记录确认每位玩家抢到的红包金额（按玩家实名姓名与 TNG 账号姓名匹配），并据此计算「点数」与「牌型」。  
因此请务必保证实名认证姓名与您的 TNG eWallet 账号姓名完全一致，否则无法识别您的抢包金额。  
玩家中奖/输赢筹码由系统按规则自动计算，不以红包面额直接入账。

### 4.6 结算

系统逐个比对庄家与闲家的牌型/点数，按倍数结算并扣除抽水：

| 结果 | 处理 |
|---|---|
| 闲家赢 | 庄家从庄池支付「倍数 × 下注」；平台抽取闲赢抽水（默认 5%） |
| 闲家输 | 闲家下注全数归庄家；平台抽取庄家盈利抽水（默认 5%） |
| 牌型/点数相同且按规则庄赢 | 按闲家输处理 |
| 等级相同且红包金额完全相同 | 平局，该对不结算，下注原路返回 |
| 庄池不足赔付 | 以庄池余额为上限，不足部分免赔 |

## 5. 点数计算

将红包金额（含小数点后两位）的所有数字相加，取个位数即为「点数」。

- 例：`3.42` → 3+4+2=9 → **9 点**  
- 总和个位为 0 时显示为 **10 点**（即「牛牛」最大点数）

---

## 6. 牌型与倍数（由高到低）

| 牌型 | 默认倍数 | 说明 | 示例 |
|---|---|---|---|
| 豹子 | 17 倍 | 三位非零相同数字 | 1.11 / 7.77 / 9.99 |
| 满牛 | 15 倍 | 整数金额 | 1.00 / 5.00 / 88.00 |
| 反顺 | 14 倍 | 三位数字严格递减 | 9.87 / 3.21 / 2.10 |
| 顺子 | 13 倍 | 三位数字严格递增 | 0.12 / 1.23 / 7.89 |
| 对子 | 12 倍 | 后两位相同且非零 | 1.22 / 7.55 |
| 金牛 | 11 倍 | 仅一位非零数字 | 0.10 / 0.50 |
| 普通 | 按 1–10 点倍数 | 以后台配置为准 | — |

实际倍数以本局游戏内显示为准。每局开始时会冻结配置快照；后台后续修改只影响下一局，不改变进行中局的牌型、倍数、费用或倒计时。

---

## 7. 牌型比较规则

1. 先比牌型等级：豹子 > 满牛 > 反顺 > 顺子 > 对子 > 金牛 > 普通。  
2. 等级不同：高等级胜。  
3. 等级相同：比红包金额，金额大者胜。  
   - 例：`2.80`（10 点）赢 `1.09`（10 点）  
4. 等级相同且金额完全相同：视为平局，该对不结算（双方下注原路返回）。  
   - 例：`2.80` 平 `2.80`

## 7a. 自爆规则

**点数不超过 3 点（1/2/3 点）即为「自爆」，直接判输**，成绩单以 💥 标记：

- 闲家自爆：直接输，下注归庄家。  
- **庄家 3 点及以下同样算自爆**：直接输给所有未自爆的闲家，按牌型倍数赔付（以庄池为上限）。  
- **庄闲双方都自爆：算庄家赢**。  
- 庄闲同点（均未自爆）：比红包金额，金额大者赢。

## 7b. 庄家费用

庄家结算时收取以下费用：

| 费用 | 规则 | 示例 |
|---|---|---|
| 上庄费 | 庄钱 × 1% | 庄钱 5000 → 收 50 |
| 服务费 | 每场固定金额（平台设定） | 38 / 场 |
| 代包费 | 本局 TNG 红包总额（按参与人数计算） | 30 人 → 红包 31.2 → 代包费 31.2 |

具体条件与金额以游戏内公告为准。

## 8a. 推广返水（3 层返水模式）

平台采用三级代理返水模式，层层返利，长期收益：

| 层级 | 返水比例 | 说明 |
|---|---|---|
| 第 3 层（自身） | 0.7% | 玩家可获取自己有效下注的 0.7% 返水 |
| 第 2 层（直属） | 0.5% | 代理可抽取下级的有效下注 0.5% 返水 |
| 第 1 层（二级） | 0.3% | 上级代理可抽取下级代理的有效下注 0.3% 返水 |

**层级关系示例：**

- 代理 A 名下有代理 B：A 抽取 B 有效下注的 0.5%；B 获得自己有效下注的 0.7%。
- 代理 B 名下有玩家 C：A 抽取 C 的 0.3%；B 抽取 C 的 0.5%；C 获得自己的 0.7%。
- 层级延伸 A → B → C → D：A 无法抽取玩家 D 的返水，仅 B 可继续享受对应层级返水（最多向上两级）。

**规则说明：**

1. 返水只计算「有效下注」，无效下注（撤回、取消局、弃权）不计入返水。
2. **庄家返水不按庄钱计算**：按该局与闲家实际对赌结算的下注总额计入，**庄家无论输赢均有返水**。
3. 返水按层级关系自动结算，系统每日结算，实时发放到余额。
4. 返水比例如有调整，平台将另行公告。

## 9. 特殊情况

| 情况 | 处理 |
|---|---|
| 无人竞标庄钱上庄 | 本局自动取消，无人参与结算 |
| 下注阶段无人下注 | 本局取消，庄池金额全额退回庄家 |
| 红包链接异常/失效 | 系统自动取消本局，所有冻结金额原路退回 |
| 抢包超时 | 由平台处理：可取消本局（冻结退回）、判未抢者弃权或人工确认后继续结算 |

## 10. 注意事项

1. 上庄前请确认账户余额足够覆盖庄池；不足将无法完成竞标。  
2. 红包链接由系统统一发出，禁止玩家私下分享或冒充系统链接。  
3. 抢包顺序按操作时间确定，请提前准备 TNG 客户端。  
4. 牌型 / 倍数 / 抽水比例 / 服务费等数值会根据运营情况调整，请以游戏内显示为准。  
5. 参与游戏前须完成：绑定邀请人、设备绑定、实名认证（含提款银行户口）并通过审核。
