# 至尊牛牛 — 公式与数值配置总表

> 全部游戏公式的唯一权威汇总，供开发实现与运营核对。  
> 标注【配置】= 后台可修改项；标注【固定】= 规则固定逻辑。  
> 版本：v1.0（2026-08-06，对应 PRD v1.7）

---

## 1. 点数与牌型

### 1.1 点数【固定】

```
点数 = 三位关键数字 [a,b,c] 之和的个位数
三位数字之和刚好 = 10 → 不按点数计算，牌型判为「牛牛」（见 1.2），点数记 10
个位数为 0 且非「牛牛」（如相加 = 20）→ 记 0 点（最小点数）
```

例：`3.42` → 3+4+2 = 9 → **9 点**；`1.28` → 1+2+8 = 11 → **1 点**；`9.83` → 9+8+3 = 20 → **0 点**；`2.80` → 2+8+0 = 10 → **牌型「牛牛」**

### 1.2 牌型判定（由高到低）【倍数配置】

红包金额固定两位小数，取三位数字 `[a, b, c]`（a=整数位个位，b、c=小数两位）：

| 优先级 | 牌型 | 判定条件 | 默认倍数 | 示例 |
|---|---|---|---|---|
| 0 | 免死 | 金额固定 = 0.01 | 判和（不参与倍数赔付） | 0.01 |
| 1 | 豹子 | a=b=c | 17 | 1.11 / 7.77 |
| 2 | 满牛 | 后两位为 00（b=c=0） | 15 | 5.00 / 88.00 |
| 3 | 顺子 | 连续递增 b=a+1 且 c=b+1（0 可作起点） | 13 | 0.12 / 7.89 |
| 4 | 反顺（倒顺） | 连续递减 b=a−1 且 c=b−1；最大 9.87；`0.98` 也算倒顺 | 14 | 9.87 / 2.10 / 0.98 |
| 5 | 对子 | b=c 且非零 | 12 | 1.22 / 7.55 |
| 6 | 金牛 | `0.X0` 形式（a=0、c=0、b=1–9） | 11 | 0.10 / 0.50 / 0.90 |
| 7 | 牛牛 | a+b+c 刚好 = 10（兜底于以上牌型之后） | 10 | 2.35 / 1.36 / 5.50 |
| 8 | 普通 | 其余 | 按点数 0–9 各自倍数【配置】 | 3.42 / 9.83 |

**优先级说明**：同时符合多个牌型时取表中更高的牌型。因此 `0.55`（和 = 10 且末两位相同）判**对子**而非牛牛，`1.36`（递增但不连续）判**牛牛**，`0.05`（非 `0.X0`）判**普通 5 点**。

**免死（0.01）规则**：抢到 RM0.01 的一方本对直接判和——退回本金、不赔不赚、不抽水、永不自爆；庄家抢到 0.01 则本局所有对子判和。

## 2. 胜负比较【固定，已确认】

```
第零步：任一方为免死（0.01）→ 本对直接判和，不再比牌
第一步：比牌型等级（豹子 > 满牛 > 顺子 > 反顺 > 对子 > 金牛 > 牛牛 > 普通）
  等级不同 → 高等级胜
第二步：等级相同 → 按该牌型规则比较
  普通：先比点数（牛牛/10点 > 9点 > … > 1点 > 0点），同点再比金额
  豹子 / 满牛 / 顺子 / 反顺 / 牛牛：比整笔金额
    例：2.80 赢 1.09（同为牛牛）
  对子：先比后两位（99>88>…>11），后两位相同再比前一位
    例：8.99 赢 9.88；9.22 赢 1.22
  金牛：只比中间金额，前后不算
    例：0.90 赢 0.10
第三步：比较键相同 → 再比整笔金额，金额大者胜
第四步：完全相同 → 庄赢（仅免死 0.01 判和）
```

### 2.1 自爆【可开关 + 阈值配置，规则已确认】

```
后台可开启/关闭自爆（默认开启）
关闭后：普通低点不再直接判输，全部走正常比牌
开启时：
点数 ≤ 3（0/1/2/3 点，普通牌型）→ 自爆，直接判输（💥 标记）
庄家 3 点及以下 → 同样自爆，输给所有未自爆闲家
庄闲双方都自爆 → 庄家赢
特殊牌型（金牛、牛牛等）→ 永不自爆（规则固定，不可配置）
  注：`0.02`/`0.03` 不再属于金牛，按普通 2/3 点判自爆
```

## 3. 下注 / 梭哈动态范围【已确认公式，比例后台可配】

```
下注下限 = 3（固定，可配）
房间下注上限 = 庄钱 × 满注比例（默认 0.6%，后台可配）
梭哈下限 = 30（固定，可配）
房间梭哈上限 = 庄钱 × 满梭哈比例（默认 5%，后台可配）

本局最高赔付倍数 M = max(特殊牌型倍数, 普通 1–10 点倍数)
默认 M = 17；若后台配置更高倍数，则按实际最高值

普通下注：本笔赔付倍数 = M
          赔付能力上限 = floor(当前可承担余额 ÷ M ÷ 1 RM) × 1 RM
          最终接受 = min(用户输入, 房间下注上限, 赔付能力上限)
梭哈：    本笔赔付倍数 = 1（固定 1:1，与牌型无关）
          最终接受 = min(用户输入, 房间梭哈上限, 当前可承担余额)
最大赔付预留金 = 最终接受下注 × 本笔赔付倍数
```

| 庄钱 | 普通下注范围（满注 0.6%） | 梭哈（满梭哈 5%） |
|---|---|---|
| 5,000 | 3 ~ 30 | 30 ~ 250 |
| 10,000 | 3 ~ 60 | 30 ~ 500 |
| 25,000 | 3 ~ 150 | 30 ~ 1,250 |

满注改成 0.5% 时：上庄 10,000 → 下注 3~50，梭哈仍 30~500。人数不再乘进上限。

余额风控示例（普通下注，默认 M=17）：

| 当前可承担余额 | 用户输入 | 赔付能力上限 | 实际接受 | 冻结预留金 |
|---|---|---|---|---|
| 200 | 50 | 11 | 11 | 187 |
| 500 | 100 | 29 | 29 | 493 |
| 1,000 | 100 | 58 | 58 | 986 |
| 1,700 | 100 | 100 | 100 | 1,700 |

余额风控示例（梭哈，倍数固定 1；房间上限按庄钱 × 5%）：

| 当前可承担余额 | 房间梭哈上限 | 用户输入 | 实际接受 | 冻结预留金 |
|---|---|---|---|---|
| 200 | 1,250 | 500 | 200 | 200 |
| 2,000 | 1,250 | 2,000 | 1,250 | 1,250 |
| 123.45 | 1,250 | 123.45 | 123.45 | 123.45 |

- 普通下注输入高于房间上限或余额能力：自动降额，不整笔拒绝；必须私下明确显示输入、余额、最高可下注及实际接受。
- 梭哈输入高于房间上限或余额：自动降到二者较小值；余额低于梭哈下限 30 才拒绝。
- 庄钱再小也不关闭梭哈（上限保底到最低额）。庄钱不够赔时，按牌型 / 点数 / 红包金额 / 下注时间统一排队，排后者喝水。
- 修改下注时，将原预留金计回可承担余额后重新计算，只补冻/解冻差额。
- 指令：普通下注发送金额数字；梭哈发送 `sh金额`；发送 `0` 撤回并释放完整预留金（封盘前）。

## 4. 抽水【已确认：只抽赢方，闲家赢 3% / 庄家盈利 5%，与费用并存】

```
闲家赢：抽水 = 闲家该笔盈利 × 3%（playerRakeRatio）
        闲家实得 = 本笔赔付倍数 × 下注 − 抽水（梭哈倍数固定 1）
庄家抽水：对赌毛利 = Σ庄赢实收 − Σ闲赢实付
        抽水 = max(0, 对赌毛利) × 5%（bankerRakeRatio）；本局亏损不抽
        从庄家庄池划至 PLATFORM_RAKE，与三费并存
平局：不抽水
输方：不额外抽水
```

- 闲家赢抽水比例默认 3%、庄家盈利抽水比例默认 5%（按本局对赌毛利），均【配置】（游戏配置 → 费用与抽水）。
- 历史局兼容：拆分前的配置快照只有单一 `rakeRatio`，进行中的旧局两侧均按旧值抽取。
- 全部抽水实收入账 `PLATFORM_RAKE`，作为「利润池」的毛利润来源（见《07-利润池与称桶分配》）。

## 5. 庄家费用【已确认公式】

| 费用 | 公式 | 示例 | 配置项 |
|---|---|---|---|
| 上庄费 | 庄钱 × 1% | 5000 → 50；7776 → 77.76 | 比例【配置】 |
| 服务费 | 每场固定金额 | 38.00 / 场 | 金额【配置】 |
| 代包费 | = 本局 TNG 红包总额 = 参与人数 × 人均单价 | 30 人 × 1.04 = 31.20 | 人均单价【配置】 |

- 三项均由庄家承担，与抽水**并存**。
- 代包费覆盖平台代发红包成本（与红包备付账勾稽）。
- 竞标须备足：庄钱 + 上庄费 + 服务费 + 按**当前在房人数**预估的代包费。截标只冻结庄钱/上庄费/服务费，代包费在关盘时按实际参与人数从剩余可用余额冻结。接近满额上庄时系统会自动把出价降到还能付代包费的上限，避免下注结束后因代包费不足取消本局。

### 5.1 红包总额【已确认】

```
红包总额 = 参与人数（庄家 + 已下注闲家）× 人均单价
```

示例：30 人 × 1.04 = **31.2**（人均单价【配置】）

## 6. 单局结算总公式

### 6.1 每对庄闲结算【固定流程】

```
对每个已下注闲家 i：
  若 任一方为免死（0.01）→ 本对判和
  否则若 闲家_i 自爆（点数≤3）→ 闲输
  否则若 庄家自爆 → 闲赢
  否则按第 2 节比较规则定胜负

  本笔赔付倍数 R_i = 梭哈单 ? 1 : 赢方牌型倍数   ← 梭哈固定 1:1，牌型倍数只用于定胜负与排序

  闲赢_i：应付 = R_i × 下注_i
          实付 = min(应付, 庄池剩余)      ← 按 6.1a 赔付顺序依次扣减庄池
          抽水 = 实付 × 3%（玩家赢抽水）
          闲家_i 实得 = 实付 − 抽水
  闲输_i：应付 = R_i × 下注_i             ← 普通按庄家牌型倍数（金牛 11 倍…），梭哈按 1 倍
          实收 = min(应付, 闲家_i 最大赔付预留金)
          未使用预留金 = 最大赔付预留金 − 实收 → 解冻退回
  闲赢/平局_i：闲家最大赔付预留金全额解冻，不抽输方

本局结束后：
  对赌毛利 = Σ庄赢实收 − Σ闲赢实付
  庄家盈利抽水 = max(0, 对赌毛利) × 5%
  再扣上庄费 / 服务费 / 代包费
```

梭哈例（默认倍数表）：梭哈 RM100 抢到豹子 → 赢只拿 **100**（闲赢抽水 3 → 实得 97）；若本局庄家只赢这一笔梭哈 RM100，对赌毛利 100，庄家盈利抽水 **5**，庄净得 95。免死（0.01）与自爆（≤3 点）判定对梭哈同样适用，只是金额按 1 倍计。

例（金牛 11 倍）：闲家下注 3，下注时按最高 17 倍预留 51；庄家抢到金牛时实扣 **33**，剩余 **18** 解冻退回。正常新下注不会发生闲家赔付不足；`shortfall` 仅保留用于部署前旧单或异常数据防御。

### 6.1a 庄钱不足时的赔付顺序【固定】

```
庄钱 = 庄家本局赔付上限，赔完即止（与闲家自身余额无关）
闲家赢的队列排序（普通与梭哈全部赢家一起排，不区分下注模式，非按下注顺序）：
  ① 牌型等级 高 → 低（梭哈按自己抢到的牌型排，不按 1:1 降级；按等级不按后台倍数，改倍数不改赔付先后）
  ② 同牌型 → 按该牌型比较规则（普通比点数；对子先后两位再前位；金牛比中间位；其余比金额）
  ③ 全部相同 → 下注时间 早 → 晚
依序赔付：
  实付_i = min(应付_i, 庄池剩余)；庄池剩余 -= 实付_i
  实付 < 应付 → 差额记 shortfall（免赔）
  庄池剩余 = 0 后的赢家 → 实付 0，全额记 shortfall，成绩单标「喝水」
  喝水者的下注预留金全额解冻退回，不倒扣
```

例（庄钱 100,000）：A 17 倍 8 点应赔 51,000 → 全额；B 11 倍 9 点应赔 33,000 → 全额（剩 16,000）；C 11 倍 7 点应赔 22,000 → 只得 16,000（免赔 6,000）；D 普通 9 点应赔 5,000 → 喝水 0。

### 6.2 庄家本局净结果【固定】

```
庄家盈利（毛） = Σ(实收闲家赔付净额) − Σ(赔付给闲家的金额)   ← 已扣抽水
庄家实际盈利 = 庄家盈利 − 上庄费 − 服务费 − 代包费
局末：庄池剩余 + 净结果相关结转 → 退回庄家可用余额
```

成绩单庄家区块口径（须逐项对得上账）：

| 项目 | 取值 |
|---|---|
| 输 / 赢 / 水 | 庄输家数；庄赢家数；平局家数 |
| 庄家盈利 | 毛盈利（已扣抽水） |
| 上庄费 / 服务费 / 代包费 | 三费逐项（成绩单以负数展示） |
| 庄家实际盈利 | 盈利 − 三费（成绩单「庄盈利 / 庄亏损」） |
| 上庄积分 | 本局结算前庄家总积分（余额口径） |
| 盈利 | = 庄家实际盈利 |
| 庄总积分 | = 上庄积分 + 盈利（即结算后总积分） |

另单列「累计做庄盈亏」为跨局统计，不与本局积分混用。

## 7. 推广返水【已确认】

```
本人佣金（每日） = 自身有效下注 × 0.7%
                 + 直属下线有效下注 × 0.5%
                 + 二级下线有效下注 × 0.3%
```

- 比例三项均【配置】；最多向上两级（A→B→C→D 时 A 拿不到 D）。
- **有效下注口径**：
  - 闲家 = 参与结算的下注（输赢均计）
  - 庄家 = 本局对赌结算的闲家下注总额（**不按庄钱**，输赢均计）
  - 不计：撤回、取消局、弃权、竞标庄钱本身；平局默认不计【开关】
- 每日自动结算、实时发放入余额。

示例：自身 1000 + 直属 2000 + 二级 500 → 7 + 10 + 1.5 = **RM 18.50**
