# 07 · 利润池与称桶分配

> 依据《利润池与称桶分配模式说明文档》（2026-08-15 需求）实现。
> 本文是实现口径的最终定义；与需求文档歧义处以本文（已与产品对齐的默认值）为准。

---

## 1. 收入端：游戏抽水（毛利润）

| 场景 | 抽水比例 | 配置项 |
|---|---|---|
| 玩家（闲家）赢 | 盈利 × **3%** | `fees.playerRakeRatio` |
| 庄家赢 | 实收 × **5%** | `fees.bankerRakeRatio` |
| 平局 / 输方 | 不抽 | — |

- 所有抽水实时入账平台科目 `PLATFORM_RAKE`，即当日**毛利润**。
- 历史局兼容：拆分前的旧局快照只有单一 `rakeRatio`，进行中的旧局两侧均按旧值执行。

```
示例（需求文档第一节）：
玩家赢 RM1,000 → 抽水 RM30
庄家赢 RM50,000 → 抽水 RM2,500
当日利润池收入 = RM2,530
```

## 2. 支出端：公司成本

```
公司支出 = 公司总流水 × 支出比例（默认 2.5%，可配置）
```

- 「公司总流水」= 当日全体用户 `TurnoverDaily.selfCents` 合计（**有效下注**口径，
  与推广返水一致：闲家计自身注、庄家计对赌闲注、平局按配置剔除、虚拟玩家不计）。
- 该 2.5% 为**账面计提**（覆盖返水、活动、红包、代理消耗等日常成本），
  不产生真实转账，仅用于计算净利润池。

## 3. 净利润池与负结转

```
净利润池 = 当日抽水合计 − 公司支出 + 前日负结转
```

- 净池 **> 0**：按第 4 节分配，未分完的余数归公司留存。
- 净池 **≤ 0**：当日**不分配**，负额自动结转次日冲抵（`carryOutCents`）。

## 4. 称桶分配（130 点制）

```
代理所得 = 净利润池 × (代理流水 ÷ 公司总流水) × (占成点数 ÷ 称桶基准130)
```

- 「代理流水」= 归属该代理名下所有玩家的当日有效流水合计。贡献比恒 ≤ 100%。
- 「占成点数」按代理等级设置（后台预设：普通 50 / 高级 60 / 核心 65 / 股东 70，可自定义 0–130）。
  实得比例 = 点数 ÷ 130（65 点 → 50%）。
- 金额按分向下取整，残差归公司留存。

```
标准示例（需求文档第八节）：
公司总流水 100,000 / 代理流水 30,000 / 净池 7,500 / 占成 65
所得 = 7,500 × 30% × (65 ÷ 130) = RM1,125 ✓
```

## 5. 结算流程与资金流

1. 每日后台任务（可关闭）在返水结算后自动结算**前一马来日**；也可在后台手动执行。
2. 结算写入 `ProfitPoolDaily`（日期唯一，天然幂等）+ `AgentProfitShare` 明细。
3. 每笔分成通过双录账本转账：`PLATFORM_PROFIT_POOL → 代理用户 USER_AVAILABLE`，
   `refType = profit_share`，幂等键 `profit-share:{date}:{agentId}`。
4. 代理收到 Bot 推送通知；资金明细中显示为「代理分成」。
5. 只能结算已结束的日期（当日实时数据仅作预估展示）。

## 6. 数据模型

| 模型 | 说明 |
|---|---|
| `Agent` | 代理/股东：绑定平台用户、占成点数、状态 |
| `AgentPlayer` | 玩家归属（一个玩家最多归属一个代理） |
| `ProfitPoolDaily` | 每日池：抽水拆分、流水、支出、结转、净池、分配、留存 |
| `AgentProfitShare` | 分配明细：流水、贡献、占成快照、金额、账本引用 |

## 7. 后台界面（资金 → 利润池分配，SUPER/FINANCE）

- **指标卡**：玩家赢抽水 / 庄家赢抽水 / 抽水合计 / 总流水 / 支出 / 结转 / 净池 / 已分配 / 留存。
- **计算过程条**：抽水 − 支出 ± 结转 = 净池，附称桶公式。
- **近 14 日趋势图**：净池、代理分配柱状 + 抽水折线（未结算日标注「预估」）。
- **代理流水贡献图**：按贡献占比排序的横向条形图，附分成金额。
- **代理管理**：新增（UID + 名称 + 占成预设）、改点数、启停用、绑定/解绑玩家。
- **称桶结算操作台**：选日期 → 预览 → 执行（幂等，二次确认）。
- **配置**：支出比例、称桶基准、自动结算开关。
- **分配历史**：近 30 个已结算业务日，可展开每个代理的分成明细。

## 8. 配置项（存于 `GameConfig`，scope=PLATFORM，key=profitPool）

| 配置 | 默认值 |
|---|---|
| `expenseRatio` 公司支出比例 | 0.025（2.5%） |
| `bucketBase` 称桶基准 | 130 |
| `autoSettle` 每日自动结算 | true |
| `tierPresets` 占成预设 | 普通50 / 高级60 / 核心65 / 股东70 |

## 9. 与需求文档的差异澄清（已按默认值实现）

| 需求文档表述 | 实现口径 |
|---|---|
| 第八节示例「30,000 ÷ 100,000 × 65 ÷ 130」结果写作 1,125 | 公式按「点数 ÷ 130 = 实得比例」实现，结果 RM1,125 与示例一致 |
| 「流水」未明确定义 | 统一采用现有**有效下注流水**口径（与返水一致） |
| 净池为负未说明 | 当日不分配，负额结转次日冲抵 |
| 2.5% 支出性质未说明 | 账面计提，不做真实转账 |
| 代理与玩家关系未定义 | 新增代理实体 + 玩家一对一归属绑定，后台管理 |
| 与推广返水的关系 | 并行运行：返水走 `PLATFORM_REBATE`，称桶分成走 `PLATFORM_PROFIT_POOL`，互不影响 |
